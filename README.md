# Кинотрек (Kinotrek)

**Telegram**: [t.me/kinotrektv](https://t.me/kinotrektv) · **WallyMates**: [worldmates.club/kinotrektv](https://worldmates.club/kinotrektv) · **Скачать**: [последний релиз](https://github.com/dncdante911/Kinotrek-TV/releases/latest)

Бесплатный торрент-кинотеатр для Android TV, Google TV, Fire TV и ТВ-приставок (Android 7–16, API 24–36): поиск фильмов и сериалов на торрент-трекерах и просмотр сразу, без скачивания. Торрент-движок TorrServer встроен в APK. Интерфейс на русском, украинском и английском. Без рекламы и регистрации.

## Две версии: ТВ и мобильная

С 2.8.7 Кинотрек выходит в двух вариантах. В каждом релизе два файла:

| Файл | Для чего |
|---|---|
| `<версия>.apk` | **ТВ-версия** — Android TV, Google TV, Fire TV, ТВ-приставки, проекторы. Управление пультом. |
| `<версия>-mobile.apk` | **Мобильная версия** — телефоны и планшеты. Управление касанием: плитки по 3 в ряд, жесты в плеере, картинка в картинке. |

Это одно приложение (тот же пакет и подпись): мобильная версия ставится поверх ТВ-версии и наоборот, библиотека и настройки сохраняются. Каждая версия обновляется своим файлом. Если на телефоне стоит ТВ-версия, Кинотрек сам предложит перейти на мобильную.

Версия 2.8.7 · TorrServer MatriX.147.1 · AGP 9.2.1 · Gradle 9.8.2 · Kotlin 2.4.21 · Compose for TV (tv-material 1.1.0, BOM 2026.09.00) · Media3 1.11.1 · compileSdk 37 / targetSdk 36.

## Возможности

- **Главная**: поиск, голосовой ввод, «Новинки» и «Популярное», ряды «Продолжить просмотр», «Избранное», «Популярные фильмы и сериалы», «Новинки кино», «Мультфильмы», «Аниме». Одинаковые фильмы в разном качестве собраны в одну карточку с постером, флагами стран и рейтингом.
- **Рекомендации**: ряд «Рекомендуем вам» и ряды «Любимый жанр: …» подбираются прямо на ТВ по открытым раздачам — досмотренное весит больше, брошенное через пару минут меньше, давние просмотры забываются. История просмотров никуда не отправляется.
- **Поиск**: Rutor, TorrentKino (раздачи RuTracker без входа), Megapeer и RuTracker; NNM-Club — только в подборках главной. Списки заранее собирает сервер Кинотрека, поэтому первые результаты появляются за пару секунд; раздачи RuTracker добавляются следом. Одна раздача с нескольких сайтов объединяется по info-hash, в обзоре — до пяти вариантов одного фильма. Фильтры по категории, качеству и стране, история запросов, голосовой поиск.
- **Качество**: «Максимальное качество» (720p / 1080p / 4K / 4K тяжёлые) — если такого нет, берётся ступень ниже; «Динамический диапазон» — приоритет SDR или HDR.
- **Подбор раздач под интернет**: приложение следит за подключением и раз в 12 часов меряет скорость. Режимы «Экономия трафика», «Обычный» и «Без ограничений» скрывают раздачи, которые сеть или приставка не потянут, и слабо сидируемые; кнопка «Показать все» возвращает их.
- **Страница фильма**: кадр из фильма на фоне (TMDB или скриншоты раздачи), постер, оригинальное название, год, длительность, качество, страны, жанры, рейтинги IMDb, Кинопоиска, TMDB, Rotten Tomatoes и Metacritic, оценки зрителей Кинотрека, описание, актёры, данные раздачи, кадры. Трейлер с YouTube играет прямо в приложении.
- **Плеер** (Media3): компактная панель для пульта, перемотка с ускорением, выбор звуковой дорожки и субтитров, скорость, формат изображения (в том числе «Авто» — без чёрных полос), таймер сна, список серий. Автоподстройка частоты кадров (24/25/50/60 Гц), в том числе на Android 12+ и Fire TV, 4K, HDR, Dolby Vision, звук Dolby и DTS — встроенным декодером или передачей на ресивер. Позиция сохраняется, следующая серия включается сама. Видео можно открыть во внешнем плеере (VLC, MX Player, Just Player, Kodi). При переключении ТВ на другой вход плеер встаёт на паузу.
- **Сериалы**: сезоны, «3 серия» вместо имени файла, отметки «Просмотрено», продолжение с той серии и того места, где остановились.
- **Аниме**: онлайн-серии с озвучкой AniLibria в день выхода и раздачи аниме с трекеров.
- **ТВ**: бесплатные открытые телеканалы из каталогов [iptv-org](https://github.com/iptv-org/iptv) и [Free-TV](https://github.com/Free-TV/IPTV), разделённые по странам (Украина, Россия, другие) и жанрам. Каждый поток проверяется, показываются только работающие; если основной поток канала не отвечает, используется запасной. Избранные и скрытые каналы. Программа передач из [epg.pw](https://epg.pw) с поправкой часового пояса и ручным сдвигом для региональных версий каналов.
- **Библиотека**: разделы «Избранное», «Смотрю», «Просмотрено», свои подборки (папки), фильтр по жанрам, сортировка. Можно добавить своё видео — файл с флешки или ссылку (magnet, mp4, m3u8). Удержание OK на карточке — быстрые действия. Резервная копия в файл или в свой Google Диск.
- **Синхронизация устройств**: ТВ, телефон и планшет связываются кодом из 8 символов («Настройки → Синхронизация устройств»). Библиотека, позиции просмотра, подборки, история поиска, избранные каналы, свои оценки и общие настройки становятся одинаковыми на всех устройствах. Записи шифруются на устройстве (AES-256-GCM): сервер хранит только шифротекст и прочитать его не может.
- **Интерфейс**: одинаково чёткий на 720p, 1080p и 4K, размер выбирается в настройках; раздел «Аниме» можно скрыть. На телефоне — компактный вид.
- **Языки**: русский (основной), украинский, английский. «Настройки → Язык · Мова · Language», по умолчанию — как в системе ТВ.
- **Открыть с помощью**: magnet-ссылки и ссылки на видео из других приложений открываются в Кинотреке.
- **Работа при блокировках**: если провайдер не пускает на трекеры, страницы загружаются через ретранслятор Кинотрека, а при необходимости — через встроенный защищённый туннель только к нему. Сами фильмы всегда идут напрямую от пиров.
- **Автообновление**: приложение проверяет GitHub Releases, скачивает APK в фоне, сверяет SHA-256 и ставит только после подтверждения. Во время просмотра ничего не всплывает.
- **Поддержать автора**: QR-коды Monobank (банка и карта) и USDT в сети TON — для зрителей из любой страны. Это добровольно: всё в приложении работает и без этого.

Встроенный TorrServer запускается по требованию отдельным процессом. Через 5 минут без просмотра он закрывает раздачи и чистит кеш; если система его остановит, он поднимается снова, и видео продолжается само. На паузе движок качает вперёд в дисковый кеш (по умолчанию до 2 ГБ).

## Вход на RuTracker

Без входа работают поиск по Rutor, TorrentKino и Megapeer и весь просмотр; через TorrentKino находится большая часть раздач RuTracker. Сам RuTracker закрыт проверкой Cloudflare, поэтому для поиска прямо по нему нужно один раз войти на сайте: «Настройки → Вход на RuTracker». Логин и пароль вводятся только на странице сайта; приложение их не видит и не хранит.

## Архитектура

```
org.trackertv.player
├── TrackerApp            — синглтоны: настройки, библиотека, поиск, обновления; язык, отчёты, статистика
├── MainActivity          — Compose-оболочка, интенты, голос, выбор файла
├── PlayerActivity        — Media3-плеер (player/: PlayerControls, PlayerMenu, FrameRates)
├── data/                 — LibraryRepository (library.json, подборки), AppSettings, StreamProfile (потолок качества, SDR/HDR), KeyStore (кеш в SQLite), I18n, Genres, Taste (рекомендации), Updater, GoogleDrive, Support
├── net/                  — SourceSearchClient (трекеры и серверный индекс), TrackerRelay и RelayTunnel (ретранслятор), ReleaseDetails, Ratings, Community (оценки зрителей), Iptv, Epg, ChannelPrefs, Anilibria, Countries
├── sync/                 — DeviceSync, SyncCrypto (синхронизация устройств, шифрование на устройстве)
├── torrent/              — LocalTorrentService, TorrServerEngine (движок отдельным процессом), TorrentEngine
├── device/               — DeviceCaps, UiScale (размер интерфейса), ExternalPlayers, Diagnostics (отчёты о сбоях), Telemetry (добровольная статистика), UiPerformance
├── web/                  — RutrackerActivity (вход), YouTubeActivity (трейлеры)
└── ui/                   — экраны home/search/release/anime/tv/library/torrent/settings/support, компоненты, тема
```

Серверная часть в каталоге [`relay/`](relay) открыта:

- `relay.py` — ретранслятор страниц трекеров, картинок и рейтингов для зрителей за блокировками; ничего не журналирует.
- `kinoindex.py` — индекс раздач: заранее собранные списки для главной и поиска; `torrentkino.py` — чтение TorrentKino для него.
- `kinorate.py` — оценки зрителей: без аккаунтов, по случайному токену установки.
- `kinosense.py` — «Похожие» и поиск по описанию: языковая модель на собственном сервере автора.
- `kinosync.py` — синхронизация устройств: хранит только зашифрованные записи и хеш кода связывания.
- `kinostats.py` — добровольная анонимная статистика; слушает только localhost, панель доступна владельцу через SSH-туннель (`tools/kinostats.bat`).

## Исходный код и лицензия

Кинотрек распространяется на условиях лицензионного соглашения [LICENSE](LICENSE): исходный код опубликован для ознакомления, копировать его, изменять и использовать для своих проектов без письменного разрешения автора нельзя. Сторонние компоненты и их лицензии — в [NOTICE.md](NOTICE.md).

Исходники приложения (`app/src/main/java`, `app/src/test`) хранятся в репозитории зашифрованными (AES-256, `tools/kinocrypt.sh`): без ключа их нельзя прочитать и собрать. Торрент-движок в `engine/` — TorrServer под GPL-3.0 — и серверная часть в `relay/` открыты.

Работа с ключом (он лежит только в `.kinotrek/key` и никогда не попадает в Git — храните копию отдельно):

```sh
bash tools/kinocrypt.sh init      # один раз: создать ключ и подключить шифрование в этой копии
bash tools/kinocrypt.sh unlock    # в новом клоне: положить ключ в .kinotrek/key и расшифровать файлы
bash tools/kinocrypt.sh status    # проверить, что в репозитории всё зашифровано
```

## Сборка

Нужны Android SDK Platform 37, JDK 17+, доступ к Google Maven/Maven Central и ключ исходников (см. выше).

```powershell
.\gradlew.bat :app:testDebugUnitTest   # юнит-тесты
.\gradlew.bat :app:lintDebug           # lint
.\gradlew.bat assembleTvRelease assembleMobileRelease   # подпись из release/signing.properties
```

В release включены R8 (обфускация кода) и сжатие ресурсов. Файлы JKS и `signing.properties` исключены из Git. Храните их резервную копию: без ключа обновить установленное приложение нельзя.

## Выпуск обновлений

1. Поднимите `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Соберите и подпишите release тем же ключом, что и прошлые версии (иначе Android откажет в установке).
3. Соберите обе версии: `assembleTvRelease` и `assembleMobileRelease`.
4. На GitHub создайте Release с тегом, равным `versionName` (например `2.8.7`). Первым приложите ТВ-APK с именем `<версия>.apk`, вторым — мобильный `<версия>-mobile.apk`: версии до 2.8.6.x берут первый APK, новые выбирают свой по слову `mobile`. Текст релиза показывается в окне обновления.

## Торрент-движок

`app/src/main/jniLibs/*/libtorrserver.so` — [TorrServer](https://github.com/YouROK/TorrServer) MatriX.147.1 с запускающей программой из `engine/runner`, собранный как отдельная исполняемая программа под arm64-v8a, armeabi-v7a, x86_64 и x86 с выравниванием на 16 КБ (имя `lib*.so` нужно только для того, чтобы Android установил его рядом с приложением). Приложение запускает движок своим процессом и общается с ним только по HTTP на 127.0.0.1. Лицензия движка — GPL-3.0 (`engine/LICENSE`). Веб-интерфейс и Swagger при сборке вырезаются (`engine/overlay`), Bonjour выключается. Пересборка или переход на новую версию:

```sh
ANDROID_NDK_HOME=/path/to/android-ndk-r28c ./engine/build.sh MatriX.147.1
```

Нужны Go (версию из go.mod TorrServer он скачает сам) и NDK r28+.
