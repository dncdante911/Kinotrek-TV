# Кинотрек (Tracker TV)

Android TV плеер для Android 9–16 (API 28–36): поиск фильмов и сериалов на торрент-трекерах и просмотр сразу, без скачивания. Торрент-движок TorrServer встроен в APK.

Версия 1.2.0 · AGP 9.2.1 · Gradle 9.8.2 · Kotlin 2.4.21 · Compose for TV (tv-material 1.1.0, BOM 2026.09.00) · Media3 1.11.1 · compileSdk 37 / targetSdk 36.

## Возможности

- **Сезонное оформление**: зимой — снег на страницах и карточках и мягкий снегопад, весной — ветка сакуры и лепестки, летом — солнечные лучи и светлячки, осенью — листопад. К праздникам (Новый год и Рождество, православная Пасха, День святого Валентина, День Независимости, Хэллоуин) своё оформление за неделю до и неделю после, на главной — салют. Один лёгкий слой поверх интерфейса, на слабых приставках вдвое меньше частиц, в плеере не работает. «Настройки → Сезонное оформление»: авто, только праздники или выключено.
- **Обложки**: постеры берутся со страниц раздач, загружаются только для карточек на экране и кэшируются (память + до 150 МБ на диске).
- **Главная**: шапка с поиском и голосовым вводом, ряды «Продолжить просмотр» (с полосой прогресса), «Избранное», «Популярные фильмы и сериалы», «Новинки кино», «Мультфильмы». Одинаковые фильмы в разном качестве собраны в одну карточку.
- **Поиск**: Rutor (три зеркала, первое ответившее) и RuTracker параллельно. Одна и та же раздача с нескольких сайтов объединяется по info-hash, сиды складываются. Мёртвые раздачи (меньше 2 сидов) отсеиваются. Фильтры по категории и качеству (720p / 1080p / 4K / HDR), история запросов, голосовой поиск.
- **Страница релиза**: постер, год, страна, длительность, жанры, описание, режиссёр и актёры, качество, видео, звук, перевод и субтитры, кадры из фильма. Со страницы трекера берётся только текст и картинки, оформление своё. Кнопки «Смотреть», «В избранное», «Другие раздачи».
- **Раздача**: экран подготовки со статусом пиров и кнопкой «Отмена». Однофайловая раздача стартует сразу. Для сериалов показывается список серий с прогрессом и отметкой «Просмотрено», кнопкой «Продолжить» или «Следующий», серии воспроизводятся подряд.
- **Плеер** (Media3): плейлист серий, «Далее: …» перед концом серии, ±10 сек кнопками ←/→, субтитры и выбор дорожки, предпочитаемый язык звука, `MediaSession` для пульта и Ассистента, понятные ошибки с «Повторить», автоподстройка частоты кадров, проверка HDR/DV/4K. Позиция сохраняется каждые 10 секунд. При сворачивании декодер освобождается.
- **Библиотека**: фильтры (избранное, не досмотрено, раздачи, ссылки, файлы), сортировка. Удержание OK открывает действия: переименовать, удалить, сбросить прогресс.
- **Открыть с помощью**: magnet-ссылки и видео-ссылки из других приложений открываются в приложении.
- **Настройки**: внешний TorrServer и проверка соединения, состояние встроенного движка, автоподстройка FPS, язык звука, автопереход к следующей серии, возможности ТВ, вход на RuTracker, обновления, поддержка автора.
- **Голосовой поиск**: через системную службу распознавания с подсказкой «Говорите…» и словами по мере распознавания. Если службы нет, открывается системный экран распознавания. Работает и на ТВ без экрана распознавания (Xiaomi и др.).
- **Автообновление**: раз в 12 часов при открытии главной приложение проверяет GitHub Releases ([Kinotrek-TV](https://github.com/dncdante911/Kinotrek-TV/releases)), скачивает APK в фоне, сверяет SHA-256 и ставит только после подтверждения. Во время просмотра ничего не всплывает.
- **Поддержать автора**: QR-коды Monobank (банка и карта). Напоминание появляется на главной раз в ~10 часов просмотра, не чаще раза за запуск, и никогда в плеере.

Встроенный TorrServer запускается по требованию и сам останавливается через 5 минут без просмотра.

## Вход на RuTracker

Без входа работает поиск по Rutor и весь просмотр. RuTracker закрыт проверкой Cloudflare, поэтому для поиска по нему нужно один раз войти на сайте: «Настройки → Вход на RuTracker». Логин и пароль вводятся только на странице сайта. Приложение их не видит и не хранит, использует только cookie сессии.

## Архитектура

```
org.trackertv.player
├── TrackerApp            — синглтоны: настройки, библиотека, поиск, обновления
├── VoiceInput            — распознавание речи через SpeechRecognizer
├── UpdateInstallReceiver — результат установки обновления
├── MainActivity          — Compose-оболочка, интенты, голос, выбор файла
├── PlayerActivity        — Media3-плеер
├── data/                 — LibraryRepository (library.json, AtomicFile, миграция со старых версий), AppSettings, ReleaseInfo, Updater, Support
├── net/                  — Http (отменяемые запросы), SourceSearchClient (с кэшем постеров), ReleaseDetails (разбор описания раздачи), TorrServerClient
├── torrent/              — LocalTorrentService (встроенный движок), TorrentEngine (выбор сервера)
├── player/               — PlaybackRequest
├── device/               — DeviceCaps
├── web/                  — RutrackerActivity (WebView для входа)
└── ui/                   — AppViewModel (навигация, диалоги), экраны home/search/release/library/torrent/settings/support, components (RemoteImage — загрузка обложек), theme
```

Библиотека и прогресс версий 0.x переносятся автоматически при первом запуске.

## Сборка

Нужны Android SDK Platform 37, JDK 17+ и доступ к Google Maven/Maven Central.

```powershell
.\gradlew.bat :app:testDebugUnitTest   # юнит-тесты
.\gradlew.bat :app:lintDebug           # lint
.\gradlew.bat assembleRelease          # подпись из release/signing.properties
```

В release включены R8 и сжатие ресурсов (`app/proguard-rules.pro` сохраняет JNI-классы TorrServer). Файлы JKS и `signing.properties` исключены из Git. Храните их резервную копию: без ключа обновить установленное приложение нельзя.

## Выпуск обновлений

1. Поднимите `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Соберите и подпишите release тем же ключом, что и прошлые версии (иначе Android откажет в установке).
3. На GitHub создайте Release с тегом, равным `versionName` (например `1.1.0` или `v1.1.0`), и приложите **один** APK. Текст релиза показывается в окне обновления.

## Ограничения

Нативная библиотека TorrServer (`io.github.secozzi:torrserver:0.1.1`, движок MatriX.141) выровнена на 4 КБ, поэтому работа на устройствах со страницей памяти 16 КБ не подтверждена. Поддержка HDR, Dolby Vision, кодеков и звука зависит от приставки, экрана и HDMI-цепочки. Диагностика показывает заявленные системой возможности. Счётчик сидов отражает последние данные сайта и не гарантирует скорость.

Используйте приложение с материалами, на просмотр которых у вас есть права.
